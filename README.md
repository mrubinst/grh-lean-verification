# Independent check of the Lean proof of RH / GRH (Alpöge–Claude, Nov 2026)

Live page: https://mrubinst.github.io/grh-lean-verification/

Home page for this project (paper explaining the proof for the Riemann zeta function, and other verifications): https://www.math.uwaterloo.ca/~mrubinst/alpoge_claude_grh/

From-scratch verification of the Lean 4 development announced in https://alpo.ge/remark.pdf:
source provenance, statement review, static audit, full compile, `#print axioms`,
and kernel replays (`leanchecker`, nanoda). Scripts used are in `scripts/` and `dist/`.
